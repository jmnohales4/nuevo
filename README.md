# Snake

Juego clásico de la serpiente como webapp en un único archivo HTML, sin dependencias.

## Jugar

Abre `snake/index.html` en el navegador. También está desplegado en GitHub Pages si está activado.

## Controles

- **Escritorio:** flechas o `WASD` para moverte, `Espacio` para pausar.
- **Móvil:** desliza en la dirección deseada.

## Características

- Canvas HTML5, lógica en JavaScript puro (sin librerías).
- La serpiente acelera a medida que come.
- Récord guardado en `localStorage`.
- Controles de teclado y táctiles.
